# Data Cleaning

A data analysis project covering data quality assessment, cleaning, integration, exploratory analysis, and dimensional modeling of e-commerce data.

## Requirements

- Python 3.10
- Jupyter Notebook

## Setup

Clone the repository and move into the project directory:

```bash
git clone git@github.com:andriniainanekena/data-cleaning.git
cd data-cleaning
````

Create and activate a virtual environment:

```bash
python -m venv .venv
```

**Linux / macOS:**

```bash
source .venv/bin/activate
```

**Windows:**

```bash
.venv\Scripts\activate
```

Install the dependencies:

```bash
pip install pandas numpy matplotlib jupyter nbclient
```

## Run the Notebook

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open the notebook and run the cells from top to bottom.
